# ISO/IEC 25010:2023

## Definition

International standard for software product quality evaluation. Replaces ISO 9126. Defines 8 quality characteristics used to evaluate all VISTA modules.

## Quality Characteristics

| # | Characteristic | What It Measures |
|---|---|---|
| 1 | Functional Suitability | Does it do what it should? |
| 2 | Performance Efficiency | Response times, resource usage |
| 3 | Compatibility | Works with other systems/environments |
| 4 | Usability | Easy to learn, operate, navigate |
| 5 | Reliability | Operates without failure |
| 6 | Security | Protects data from unauthorized access |
| 7 | Maintainability | Easy to modify and extend |
| 8 | Portability | Easy to transfer to different environments |

## Evaluation in VISTA

- Used by all 4 module papers (SOP 3)
- Likert scale evaluation by Manager + Owner
- Interpretation scale varies slightly by paper (4-point vs 5-point)
