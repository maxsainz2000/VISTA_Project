# UTAUT2

## Definition

Extended version of UTAUT by Venkatesh et al. (2012). Measures user acceptance and adoption of technology. Used in all VISTA module evaluations (SOP 4).

## Constructs Evaluated in VISTA

All 4 module papers measure two dimensions:

1. **User Acceptance** — willingness to adopt and continue using the system
2. **Perceived Ease of Use and Usefulness as Efficacy** — how easily users interact with the system and how effectively it improves their work

## Evaluation Method

- 5-point Likert scale (Strongly Disagree → Strongly Agree)
- Respondents: Manager + Owner (n=2)
- Weighted mean analysis

## Key Findings from Literature

- Performance expectancy, effort expectancy, and facilitating conditions are strongest predictors (Chen & Cheng, 2023)
- Ease of use and usefulness most significant for Philippine MSME context (Dela Cruz & Villanueva, 2024)
- Price value is a significant barrier for resource-limited users
