# Descriptive-Developmental Research Design

## Definition

A research design combining systematic documentation of existing problems (descriptive) with building a technological solution (developmental). Used by all 4 VISTA module papers.

## SOP Structure (All Papers)

| SOP | Phase | Method |
|---|---|---|
| SOP 1 | Describe current practices/problems | Thematic analysis of interviews + observation |
| SOP 2 | Identify requirements/interventions | Qualitative requirement specification |
| SOP 3 | Evaluate technical quality | [[iso-25010-2023\|ISO 25010:2023]] — weighted mean |
| SOP 4 | Evaluate user acceptance | [[utaut2\|UTAUT2]] — weighted mean |

## Respondents

All papers: Manager + Owner of [[villon-farm-supply|Villon Farm Supply]] (purposive sampling, n=2)

## Key Strength

Problem-to-feature traceability — each documented problem (SOP 1) maps directly to a specific software feature (SOP 2), ensuring the built system addresses real, observed needs.
