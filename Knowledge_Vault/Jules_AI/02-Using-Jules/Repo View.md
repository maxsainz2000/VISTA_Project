# Repo View

A workspace scoped to one repository: task history, running tasks, and environment configuration in one place.

## Opening it

1. Click any repository name in the sidebar task list, or
2. Select a repo from the task picker and click into it after starting a task

## Task history

Inside, all tasks for that repo are listed:

- **Running** tasks at the top
- **Completed** tasks with full logs and diffs
- **Failed** or **waiting** tasks clearly labelled

Click any task to reopen it, review the plan, or continue giving feedback.

## Starting a scoped task

**New task** in the top-right preselects this repo and branch — enter your prompt and setup script as usual.

The repo view is also where the per-repository controls live: **Configuration** ([[Environment Setup]]), **Proactivity** ([[Suggested Tasks]]), **Scheduled** ([[Scheduled Tasks]]), and **Knowledge** ([[Memory and Knowledge]]).
