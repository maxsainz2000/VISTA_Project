# Tag Taxonomy

Tags are hierarchical, so `#jules/api` in the tag pane folds up everything below it.

| Tag | Use for |
| --- | --- |
| `#jules/setup` | Account, GitHub connection, first run, environment scripts |
| `#jules/environment` | The VM, preinstalled tools, env vars, snapshots |
| `#jules/tasks` | Running, pausing, deleting, reviewing tasks |
| `#jules/prompting` | How to phrase work for Jules |
| `#jules/automation` | Scheduled tasks, suggested tasks, CI-triggered work |
| `#jules/api` | REST API surface |
| `#jules/cli` | Jules Tools command line |
| `#jules/integration` | Render, GitHub Actions, MCP servers |
| `#jules/github` | Anything touching repos, branches, PRs, issues |
| `#jules/limits` | Plans, quotas, concurrency |
| `#jules/troubleshooting` | Failures, retries, debugging |
| `#jules/security` | Keys, permissions, safe operation |
| `#jules/changelog` | Release-history notes |

Cross-cutting markers:

- `#moc` — map-of-content notes
- `#alpha` — documents a surface Google labels experimental
