## 3. ESC/POS or PDF Receipt Rendering

**Module:** POS
**Source:** POS-18 What's Next
**Description:** A rendering layer that takes the `ReceiptBody` blocks (already generated by POS-18) and formats them for:
- **Thermal printers** using ESC/POS commands (80mm or 58mm paper width)
- **PDF output** for digital receipts or reprints
- Includes width-limited formatting and currency symbol substitution (₱ → PHP when needed for ASCII printers).
**Why deferred:** The receipt data model and VAT bucket formatting (POS-18) had to be built first. Rendering is a separate output concern.
**Depends on:** POS-18 (Receipt Body VAT Bucket Printing — completed).
